# Учебный frontend-проект

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт учебного интернет-магазина.

## История выполнения

- Практическая работа 1: создан Git-репозиторий, опубликован проект на GitHub Pages.
- Практическая работа 2: создан HTML-каркас стартовой страницы и выполнено базовое CSS-оформление.
- Практическая работа 3: добавлена форма заявки, модальное окно и базовая валидация.
- Практическая работа 4: добавлены CSS-переменные, состояния интерфейса и упорядочена структура стилей.
- Практическая работа 5: создана многостраничная структура сайта, добавлены единая навигация, якорные ссылки, хлебные крошки, уникальные `title` и `meta description`.
- Практическая работа 6: добавлены Flexbox-навигация, Grid-сетка карточек и Grid-структура каталога с фильтрами.

## Реализованные элементы интерфейса

- единая навигация между страницами;
- якорные ссылки на главной странице;
- хлебные крошки на внутренних страницах;
- карточки товаров;
- кнопки заказа;
- модальное окно с формой заявки;
- базовая HTML- и JavaScript-валидация;
- сообщение об успешной отправке;
- блок фильтров на странице каталога.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога по схеме «фильтры + товары»;
- `gap` для задания промежутков между элементами;
- `grid-template-columns`, `grid-template-areas` и `grid-area` для структуры каталога.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- псевдокласс `:target` для подсветки раздела при переходе по якорю;
- БЭМ-подобное именование классов;
- структурированный файл `css/style.css`.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — страница каталога;
- `contacts.html` — страница контактов;
- `css/style.css` — общий файл стилей;
- `js/main.js` — JavaScript для модального окна и формы;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Используемые технологии

## Проверка практической работы №5

1. Открыть `index.html`.
2. Проверить переходы между `index.html`, `catalog.html` и `contacts.html`.
3. Проверить ссылки на `#advantages`, `#popular`, `#contacts`.
4. Открыть внутренние страницы и проверить хлебные крошки.
5. Проверить уникальные `title` и `meta description`.

## Проверка практической работы №6

1. Проверить Flexbox у `.site-nav__list`.
2. Проверить Grid у `.product-grid`.
3. Открыть `catalog.html` и проверить блок фильтров слева и товары справа.
4. В DevTools проверить `grid-template-columns`, `grid-template-areas`, `grid-area` и `gap`.
5. Проверить, что кнопки товаров по-прежнему открывают модальное окно.
