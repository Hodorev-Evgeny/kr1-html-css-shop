# Учебный frontend-проект

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт учебного интернет-магазина.

## История выполнения

- Практическая работа 1: создан Git-репозиторий, опубликован проект на GitHub Pages.
- Практическая работа 2: создан HTML-каркас стартовой страницы и выполнено базовое CSS-оформление.
- Практическая работа 3: добавлена форма заявки, модальное окно и базовая валидация.
- Практическая работа 4: добавлены CSS-переменные, состояния интерфейса и упорядочена структура стилей.
- Практическая работа 5: создана многостраничная структура сайта, добавлены единая навигация, якорные ссылки и хлебные крошки.
- Практическая работа 6: добавлены Flexbox-навигация и Grid-раскладка карточек и каталога.
- Практическая работа 7: выполнен рефакторинг CSS-классов по методологии БЭМ.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `section` — универсальный раздел;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — переиспользуемая кнопка;
- `success-message` — сообщение об успешной отправке;
- `site-footer` — подвал сайта.

## Примеры БЭМ

### Блок

`product-card` — самостоятельный компонент карточки товара.

### Элемент

`product-card__title`, `product-card__description`, `product-card__price`,
`product-card__button` — элементы карточки.

### Модификатор

- `product-card--featured` — выделенная карточка;
- `site-nav__link--active` — активная ссылка навигации;
- `button--primary` — основная кнопка;
- `button--secondary` — второстепенная кнопка.

## Что изменено в практической работе №7

- классы приведены к смысловой БЭМ-системе;
- `product-grid` переименован в `products-grid`;
- у хлебных крошек добавлены `breadcrumbs__link` и `breadcrumbs__current`;
- поля формы приведены к `order-form__field`, `order-form__label`,
  `order-form__input`, `order-form__select`, `order-form__textarea`;
- кнопки используют базовый блок `button` и модификаторы;
- добавлен пример модификатора `product-card--featured`;
- стили не задаются через `id`;
- inline-стили не используются;
- уменьшена зависимость CSS от вложенности HTML;
- сохранены `id`, необходимые для якорей и JavaScript.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `contacts.html` — контактная информация;
- `css/style.css` — общий файл стилей;
- `js/main.js` — JavaScript модального окна и формы;
- `README.md` — описание проекта;
- `.gitignore` — список исключённых Git-файлов.

## Проверка работы

1. Открыть `index.html`.
2. Проверить навигацию и карточки.
3. Нажать «Заказать» и проверить открытие модального окна.
4. Проверить закрытие и отправку формы.
5. Открыть `catalog.html` и проверить Grid и фильтры.
6. Открыть `contacts.html` и проверить хлебные крошки.
7. В DevTools показать БЭМ-блоки, элементы и модификаторы.
8. Проверить, что CSS не использует `#id` для стилизации.
