# Контрольная работа №1 — ShopProject

Тема: «HTML и CSS: разработка многостраничного сайта».

Проект представляет собой учебный многостраничный интернет-магазин, созданный без CSS-фреймворков. В проекте используются семантический HTML, CSS-переменные, Flexbox, CSS Grid, БЭМ, формы, модальное окно и базовая HTML-валидация.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров и фильтры;
- `product.html` — подробная карточка товара и таблица характеристик;
- `order.html` — отдельная страница оформления заявки;
- `contacts.html` — контактная информация;
- `css/style.css` — общий файл стилей;
- `js/main.js` — минимальная логика модального окна и формы;
- `README.md` — описание проекта.

## Самостоятельные доработки — реализовано сейчас

Из раздела 14 методических указаний выбраны и реализованы 4 пункта:

1. **Более подробная карточка товара** — отдельная страница `product.html` с подробным описанием, списком особенностей, ценой и действиями.
2. **Расширенная таблица характеристик** — таблица с `caption`, `thead`, `tbody`, `th`, `td` и несколькими параметрами товара.
3. **Sticky-фильтр каталога** — боковой блок фильтров использует `position: sticky`.
4. **Фиксированная кнопка «Наверх»** — на страницах добавлена кнопка с `position: fixed` и `z-index`.

## Как проверить проект

1. Открыть `index.html`.
2. Проверить единую навигацию.
3. Открыть `catalog.html` и прокрутить страницу — фильтр должен оставаться видимым благодаря `position: sticky`.
4. Открыть `product.html` и проверить подробную карточку и таблицу характеристик.
5. Открыть `order.html` и проверить форму и HTML-валидацию.
6. Проверить кнопку «Наверх» в правом нижнем углу страницы.
7. На `index.html` или `catalog.html` проверить существующее модальное окно через кнопку «Заказать».
8. В DevTools показать Flexbox, Grid, БЭМ и позиционирование.
